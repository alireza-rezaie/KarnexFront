# Karnex Frontend

## Overview

This repository contains the frontend for Karnex, a Persian project-management and team-collaboration system.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Radix UI

## Requirements

- Node.js 20+
- npm

## Installation

```bash
npm ci
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Project Status

Frontend prototype currently being prepared for backend integration.
